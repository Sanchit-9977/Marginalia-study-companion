# Marginalia — Spaced Repetition Study Companion

## Overview
Marginalia is a study companion designed to help students learn, revise, and stay focused. It combines spaced-repetition flashcards, focused study sessions, and progress tracking in one simple web application.

## Problem Statement
Students often struggle to remember what they study and maintain a consistent revision routine. Switching between different apps for notes, revision, timers, and progress tracking can make studying less organized and effective.

## Solution
Marginalia brings essential study tools together in one platform. Students can create flashcard decks, review concepts using spaced repetition, focus using a Pomodoro-style timer, and track their study progress.

## Key Features
- Create and manage flashcard decks
- Spaced-repetition based revision
- Study and review flashcards
- Pomodoro focus timer
- Study progress tracking
- Dashboard for monitoring learning activity
- Import and export study data
- Simple and student-friendly interface

## How It Works
1. Create a study deck.
2. Add flashcards for the topic you want to learn.
3. Review the flashcards regularly.
4. Use focused study sessions to improve productivity.
5. Track your study activity and progress.
